## Логика матчинга

Цель — не найти покупателя по протоколу, а понять, **что открылось на месте после покупки**.

Для каждого лота:
1. Берём дату продажи
2. Ищем бизнесы, **появившиеся рядом (≤250м) в течение года** — присутствующие в срезе 2GIS после покупки, но отсутствовавшие в предыдущем
3. Отсеиваем невалидных кандидатов (госслужбы, постаматы, экоконтейнеры и т.д.)
4. Проверяем соответствие площади лота типу бизнеса
5. Берём ближайшего кандидата с наилучшим confidence

**Срезы 2GIS:** 21 срез от 2020-04 до 2026-04. Новые бизнесы = те, что есть в curr, но не было в prev.

### Confidence

| Уровень | Условие |
|---------|---------|
| `high` | 1 кандидат, расстояние ≤30м |
| `medium` | ≤3 кандидата, расстояние ≤100м |
| `low` | остальные |

В финальный файл попадают только `high` и `medium`.

## История зданий

`build_business_history.py` собирает по каждому лоту три колонки из всех 21 срезов в радиусе 250м:

| Колонка | Содержимое |
|---------|-----------|
| `история_бизнесов` | Все бизнесы, когда-либо появлявшиеся рядом |
| `сейчас_в_здании` | Бизнесы, присутствующие в последнем срезе (2026-04) |
| `были_в_здании` | Появлялись в каком-либо срезе, но в 2026-04 уже нет |

**Важно:** история — это коммерческий контекст района (радиус 250м), а не конкретного помещения. Нельзя сказать, какой именно юнит в здании занял каждый бизнес.

## Приложение

```bash
"/c/Users/Ксения/AppData/Roaming/Python/Python39/Scripts/streamlit.exe" run property_goals/app.py
```

Что показывает:
- Карта лотов с попапом: адрес, цена, дата торгов, арендатор, время до открытия; сейчас / были в здании; история здания
- Фильтры: год, округ, этаж, площадь, цена, качество совпадения, найден ли арендатор
- Таблица: арендатор, категория, сейчас/были в здании, рекомендуемые сети, цены, ссылка
- Аналитика: KPI, топ компаний и категорий, 6 инсайт-карточек (включая кто остаётся / кто уходит из зданий), матчи по годам

## Ключевые находки (из данных)

- **33% арендаторов — ПВЗ маркетплейсов** (Wildberries, Ozon, ЯМ), медиана площади ~93 м²
- **Публичное предложение** закрывается на ~25% ниже старта; арендатора находят реже, чем у конкурентных торгов
- **~66% арендаторов — 1-й этаж, ~30% — подвал**; 2-й этаж и выше — единицы
- **Медиана открытия — 159 дней**, 23% открываются в первые 3 месяца
- **Красота — второй кластер** (~70 адресов: барбершопы, ногтевые, косметологи)
- **Сетевой ретейл остаётся** (Пятёрочка 92%, Wildberries 91%, Винлаб 90%); B2B-офисы уходят (страхование, IT, полиграфия)

## Ограничения

- Нет кадастрового номера → матч по адресу и координатам, не по конкретному помещению
- На одном адресе может быть несколько помещений и несколько бизнесов
- `likely_company` и `likely_usage` — вероятностная реконструкция, не юридически точная
- История здания = радиус 250м, не конкретный юнит
