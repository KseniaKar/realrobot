## Логика матчинга

Цель — не найти покупателя по протоколу, а понять, **что открылось на месте после покупки**.

Для каждого лота:
1. Берём дату продажи
2. Ищем бизнесы, **появившиеся рядом (≤250м) в течение года** — то есть присутствующие в срезе 2GIS после покупки, но отсутствовавшие в предыдущем срезе
3. Отсеиваем неподходящих кандидатов (госслужбы, постаматы, экоконтейнеры и т.д.)
4. Проверяем соответствие площади лота типу бизнеса
5. Берём ближайшего кандидата с наилучшим confidence

**Срезы 2GIS:** хронологическая цепочка от 2021-10 до 2026-04 с парами (prev → curr). Новые бизнесы = те, что есть в curr, но не было в prev.

### Confidence

| Уровень | Условие |
|---------|---------|
| `high` | 1 кандидат, расстояние ≤30м |
| `medium` | ≤3 кандидата, расстояние ≤100м |
| `low` | остальные |

В финальный файл попадают только `high` и `medium`.

### Фильтры невалидных кандидатов

- **По рубрике:** водоматы, постаматы, зарядки телефонов, справочные госслужбы, ЖКУ, новостройки, общественные организации
- **По названию:** eco-контейнеры, пункты сбора батареек, адресообразные названия ("Романов переулок, 7")
- **По площади:** для категорий с известными требованиями (алкомаркеты, ПВЗ, супермаркеты и др.) — площадь лота должна укладываться в допустимый диапазон (с 4× tolerance)

## Пересборка матчинга

```bash
# Основной pipeline (запускать в этом порядке):
py process_gap_snapshots.py        # разбор срезов 2GIS → moscow/{label}.with_norm.csv
py match_gap_snapshots.py          # матчинг по парам срезов → gap_matches_summary.csv
py merge_gap_matches.py            # слияние в enriched_geo.csv (идемпотентно)
py revalidate_matches.py           # очистка невалидных кандидатов
```

При появлении нового среза 2GIS: добавить пару в `SNAPSHOT_PAIRS` в `match_gap_snapshots.py` и перезапустить pipeline.

## Приложение

```bash
streamlit run property_goals/app.py
```

Что показывает:
- Карта лотов с карточкой: адрес, цена, дата торгов, арендатор, время до открытия бизнеса
- Фильтры: год, округ, этаж, площадь, цена, качество совпадения, найден ли арендатор
- Таблица с арендатором, категорией, рекомендуемыми сетями, ценами
- Инсайты: топ компаний, ключевые выводы, покрытие по годам

## Ограничения

- Нет кадастрового номера → матч по адресу и координатам, не по конкретному помещению
- На одном адресе может быть несколько помещений и несколько бизнесов
- `likely_company` и `likely_usage` — вероятностная реконструкция, не юридически точная
