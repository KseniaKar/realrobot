# Property Goals — контекст для агента

## Цель проекта

Восстановить пост-покупочное использование коммерческих помещений, проданных на аукционах mos.ru (investmoscow.ru) в 2022–2026 годах. Данные о победителях аукционов закрыты — определяем, что появилось на объекте после покупки, по срезам справочника 2GIS.

Задача: к каждому из 3868 купленных лотов подобрать вероятную компанию-арендатора и категорию использования.

**Термин:** "срез" = снимок базы 2GIS на определённую дату (не говорим "снапшот").

### Срезы 2GIS (moscow/) — 21 срез

| Метка | Тип |
|-------|-----|
| `2020-04` … `2021-10` | Ранние срезы |
| `2022-01` … `2024-10` | Gap-срезы (покрывают исторический пробел) |
| `2025-05`, `2025-07`, `2025-09`, `2025-11` | Промежуточные |
| `2026-02`, `2026-03`, `2026-04` | Свежие срезы |

Исторический пробел 2021-10 → 2025-09 (~4 года) **закрыт** gap-срезами.

## Логика матчинга

- Лот продан → ищем бизнес, появившийся рядом (≤250м) в течение **до 1 года** после продажи
- Сравниваем пары срезов (prev → curr): бизнес есть в curr, но не было в prev → кандидат
- `MIN_AFTER_DAYS = 0`, `MAX_AFTER_DAYS = 365`, `MAX_DISTANCE_M = 250`
- Confidence: `high` (1 кандидат ≤30м), `medium` (≤3 кандидата ≤100м), `low` иначе
- Многолотовые здания: если несколько лотов на одном адресе — всем присваивается `multilot_building = "1"`, confidence не снижается
- В enriched CSV попадают только `high`/`medium` матчи

Синхронизированы между `match_gap_snapshots.py` и `build_business_history.py`.

- Терминалы оплаты, Платёжные терминалы
- Детские развлекательные автоматы, Фотокабины / Автоматы фотопечати

- Государственные дошкольные учреждения, Общеобразовательные школы
- Органы государственной власти, Многофункциональные центры, Библиотеки
- Аварийные / справочные / экстренные службы
- Жилищно-коммунальные, Правоохранительные органы
- Новостройки, Общественные / политические организации

**`IMPLAUSIBLE_NAME_SUBSTRINGS` (по имени):**
- банкомат, 5post, 5 post, qiwi, киви
- бери заряд, зарядная станция
- автомат по продаже кофе, кофейный автомат, автомат с , автомат копировальных

`revalidate_matches.py` дополнительно проверяет соответствие площади лота требованиям категории из `../retailstreets_parser/data/retailstreets_requirements.csv` (4× tolerance).

### Нормализация брендов

`BRAND_ALIASES` в обоих скриптах приводит варианты к единому имени:
Wildberries/вайлдберриз → "Wildberries", OZON/озон → "Ozon", CDEK/сдэк → "СДЭК" и т.д.

В `build_business_history.py`: для известных брендов (`KNOWN_BRANDS`) убирается суффикс рубрики — хранится просто "Wildberries", а не "Wildberries (Грузоперевозки)".

История дедуплицируется по имени бренда (key = canonical.lower()) — одна запись на компанию независимо от смены рубрик в 2GIS.

## Колонка `история_бизнесов`

Для каждого лота собирается полная история всех бизнесов, когда-либо появлявшихся по этому адресу во всех 21 срезах 2GIS. Не привязана к дате покупки — показывает весь коммерческий контекст здания.

- Хранится как pipe-separated список: `"ВкусВилл | Пятёрочка (Спецмагазины) | ..."`
- Используется только первая рубрика (без суб-рубрик) для краткости
- Для известных брендов — только имя без категории
- Пересобирается скриптом `build_business_history.py`

## Приложение (app.py)

- Карта лотов с попапом: адрес, площадь, цена, дата торгов, арендатор, категория, дней до открытия; история помещения; предупреждение о многолотовом здании
- Фильтры в сайдбаре: форма проведения, качество совпадения, арендатор найден, год, округ, этаж, площадь, цена
- Таблица: арендатор, категория, история помещения, рекомендуемые сети, цены, ссылка
- Аналитика: KPI метрики (уникальные арендаторы, доля маркетплейсов, медиана открытия, доля 1-го этажа), топ компаний и категорий, 4 инсайт-карточки, матчи по годам

## Ключевые находки (из данных)

- **33% арендаторов — ПВЗ маркетплейсов** (Wildberries, Ozon, ЯМ), медиана площади ~93 м²
- **Публичное предложение** (нисходящий аукцион) закрывается на 25% ниже старта; арендатора находят реже, чем у конкурентных торгов
- **~66% арендаторов — 1-й этаж, ~30% — подвал**; 2-й этаж и выше — единицы
- **Медиана открытия — 159 дней**, 23% бизнесов открываются за первые 3 месяца
- **Красота — второй кластер** (~70 адресов: барбершопы, ногтевые, косметологи)

## Ограничения данных

- Нет кадастрового номера → матч по адресу + координатам, не по объекту
- На одном адресе может быть несколько помещений — неизвестно, какое именно занял бизнес
- `likely_company` и `likely_usage` — вероятностная реконструкция, не юридически точная
- `multilot_building = "1"` — флаг: один арендатор на несколько лотов в здании
