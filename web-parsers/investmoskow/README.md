# 🏗️ investmoscow — Look-Alike модель для предсказания превышения цены

Предсказание превышения цены на торгах по продаже нежилых помещений Москвы с помощью ансамбля CatBoost + KNN.

## 📊 Кратко

- **Данных:** 2 806 лотов (2 236 train + 248 holdout + 64 активных)
- **Модель:** CatBoost (20%) + KNN (80%) — Look-Alike
- **MAE на holdout:** 27.48%
- **Признаков:** 30 (числовые, категориальные, бинарные)
- **KNN:** Среднее 5 ближайших соседей, округлённое до шага аукциона

## 🚀 Запуск

### Streamlit приложение

```bash
python -m streamlit run model/app_validation.py
```

Открой: http://localhost:8501

**Что показывает:**
- Карта 248 завершённых лотов с цветовой кодировкой ошибки
- При клике: 5 Look-Alike соседей с линиями связи
- Предсказания: CatBoost, KNN, Ансамбль
- Дата завершения торгов для каждого соседа
- Ссылки на investmoscow.ru

### EDA анализ

```bash
python model/eda_analysis.py
```

Генерирует 25 графиков в папке `model/eda/`
