# Парсер investmoscow.ru

Парсер для сбора данных о продаже нежилых помещений с сайта [Инвестиционный портал Москвы](https://investmoscow.ru/tenders/).

## Установка

```bash
pip install playwright requests
playwright install chromium
```

## Запуск

```bash
python parser.py
```

## Результат

Данные сохраняются в папку `data/`:

- `investmoscow_YYYY-MM-DD.csv` — результат парсинга (UTF-8-sig для Excel)
- `progress.json` — прогресс для возобновления прерванного парсинга

## Поля CSV

| Поле | Описание |
|------|----------|
| `url` | Ссылка на объявление |
| `площадь м²` | Площадь объекта (запятая как десятичный разделитель) |
| `цена руб.` | Цена (пробелы как разделители тысяч, запятая для копеек) |
| `адрес` | Адрес объекта |
| `функциональное_назначение` | Назначение помещения |
| `тип_входа` | Тип входа |
| `этаж` | Этаж расположения |
| `этажность` | Количество этажей в здании |
| `метро` | Ближайшие станции метро |
