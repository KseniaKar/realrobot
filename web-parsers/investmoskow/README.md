# investmoscow — CatBoost модель для предсказания превышения цены

Предсказание превышения цены на торгах по продаже нежилых помещений Москвы.

## Кратко

- **Данных:** 2 806 лотов (2 236 train + 101 holdout + 64 active)
- **Модель:** CatBoostRegressor (основная) + KNN (look-alike карта)
- **Медианная ошибка:** 7.9%
- **Признаков:** 33 (+3 признака задатка)
- **Парсер:** API + HTML страниц investmoscow.ru (143 активных лота)

## Запуск

### Streamlit приложение

```bash
python -m streamlit run model/app_validation.py
```

Открой: http://localhost:8501

**Что показывает:**
- Карта завершённых лотов с цветовой кодировкой ошибки CatBoost
- При клике: 5 Look-Alike соседей с линиями связи
- **Предсказание CatBoost** (основная модель)
- Медиана соседей (справочно)
- Ссылки на investmoscow.ru

### Парсинг активных торгов

```bash
python parser.py
```

Парсит активные торги с задатком, шагом аукциона, кадастровым номером.

## Признаки задатка

| Признак | Описание | Важность |
|---------|----------|----------|
| `deposit_pct` | % задатка от цены | — |
| `is_min_deposit` | Задаток = 500к (повторные торги) | **5.3% (9-е место)** |
| `is_cheap_lot` | Цена < 5 млн | — |

### Статистика задатков

| % задатка | Лотов | Механизм |
|---|---|---|
| **10%** | 56% | Стандартный аукцион |
| **Фикс. 500 тыс** | 36% | Повторные торги |
| **20%** | 8% | Крупные объекты |

## Метрики модели (holdout n=101)

| Модель | MAE | **Медианная ошибка** | R² |
|--------|-----|---------------------|----|
| **CatBoost (с задатком)** | 26.9% | **7.9%** | -0.247 |
| CatBoost (без задатка) | 26.6% | 8.3% | -0.184 |
| Ансамбль 50/50 | 30.8% | 30.0% | -0.209 |
