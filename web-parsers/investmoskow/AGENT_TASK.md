# investmoscow — CatBoost модель для предсказания превышения цены

**Streamlit:** `python -m streamlit run model/app_validation.py`

---

## 1. ДАННЫЕ

### 1.1 Источники

| Источник | Файл | Записей | Описание |
|----------|------|---------|----------|
| **Активные торги** (апрель 2026) | `data/investmoscow_2026-04-08.csv` | 143 | Парсинг API + HTML страниц investmoscow.ru |
| **Завершённые торги** | `../investmoskow_before/data/investmoscow_completed_2026-04-04_geocoded.csv` | 2 839 | Исторические данные + протоколы |
| **Дешёвые лоты (< 5 млн)** | `../investmoskow_before/data/investmoscow_completed_cheap_under5mln.csv` | 305 | Вынесены отдельно |
| **Очищенные (≥ 5 млн)** | `../investmoskow_before/data/investmoscow_completed_2026-04-04_geocoded_cleaned.csv` | 2 534 | Основной датасет без дешёвых |

### 1.2 Обработка данных

1. **Парсинг активных торгов** (`parser.py`):
   - API: `POST https://api.investmoscow.ru/.../searchtenderobjects`
   - HTML страниц: извлечение задатка, шага аукциона, кадастрового номера
   - Поля: площадь, цена, адрес, этаж, тип_входа, метро, **размер_задатка_руб**, **шаг_аукциона_руб**, **кадастровый_номер**, даты

2. **Геокодирование** (`geocode_addresses.py`):
   - Nominatim (OpenStreetMap) с кэшированием
   - Добавлены: `latitude`, `longitude`

3. **Признаки задатка** — добавлены в dataset:
   - `deposit_pct` — процент задатка от начальной цены
   - `is_min_deposit` — задаток = 500 тыс (повторные торги, «лёгкий вход»)
   - `is_cheap_lot` — начальная цена < 5 млн

### 1.3 Разделение данных

| Набор | Записей | Target | Назначение |
|-------|---------|--------|------------|
| **Train** | 2 236 | Известно превышение | Обучение CatBoost |
| **Holdout** | 101 | Реальные данные | Валидация модели |
| **Active (без задатка)** | 64 | Нет завершённой цены | Прогноз |

> **Holdout** = лоты, которые были активными, но уже завершились и имеют реальную цену продажи.

## 4. МОДЕЛЬ

### 4.1 Архитектура

**CatBoostRegressor** — основная модель предсказания
**KNN (Look-Alike)** — только для поиска похожих лотов (НЕ для предсказания)

| Компонент | Назначение |
|-----------|------------|
| **CatBoostRegressor** | Предсказание превышения цены |
| **KNN (5 соседей)** | Look-Alike карта: визуализация похожих лотов |

### 4.2 CatBoostRegressor

```python
CatBoostRegressor(
    iterations=500, learning_rate=0.01, depth=4,
    l2_leaf_reg=10, min_data_in_leaf=20,
    loss_function='MAE', random_seed=42
)
```

### 4.3 Результаты валидации (Holdout n=101)

| Модель | MAE | **Медианная ошибка** | R² |
|--------|-----|---------------------|----|
| **CatBoost (с задатком)** | **26.9%** | **7.9%** | -0.247 |
| CatBoost (без задатка) | 26.6% | 8.3% | -0.184 |
| Ансамбль 50/50 | 30.8% | 30.0% | -0.209 |

### 4.4 Top-10 признаков CatBoost

| Признак | Важность |
|---------|----------|
| этажность | 12.1% |
| price_density | 11.5% |
| latitude | 8.7% |
| шаг_аукциона_pct | 7.8% |
| цена_за_м2_calc | 7.8% |
| longitude | 7.2% |
| расстояние_до_центра | 6.5% |
| расстояние_до_центра_округа | 5.7% |
| **is_min_deposit** ← ЗАДАТОК | **5.3%** |
| начальная_цена_руб | 4.7% |

### 4.5 Ключевые выводы

**Что работает:**
- **Медианная ошибка 7.9%** — типичное предсказание близко к реальности
- `is_min_deposit` — 9-й по важности признак (модель использует задаток)
- KNN НЕ улучшает ансамбль — добавляет шум

**Проблемы:**
- Отрицательный R² — модель плохо предсказывает экстремальные значения
- Все корреляции слабые (|r| < 0.15)

## 7. ЗАПУСК

### 7.1 Streamlit приложение

```bash
python -m streamlit run model/app_validation.py --server.headless true --server.port 8501
```

**Функционал:**
- Карта завершённых лотов с цветовой кодировкой ошибки CatBoost
- При клике на лот:
  - 5 Look-Alike соседей (синие маркеры)
  - Красные пунктирные линии связи
  - **Предсказание CatBoost** (основная модель)
  - Медиана соседей (справочно)
  - Ссылки на investmoscow.ru

### 7.2 Парсинг

```bash
python parser.py
```

Парсит активные торги с задатком, шагом аукциона, кадастровым номером.

## 9. РЕКОМЕНДАЦИИ

### 9.1 Что можно улучшить

1. **Добавить больше признаков** — тип недвижимости, инфраструктура района
2. **Отдельная модель для повторных торгов** — лоты с фикс. 500к задатком имеют другую динамику
3. **Квантильная регрессия** для оценки хвостов распределения
4. **Классификация «горячих» лотов** (превышение > 50%)
5. **Обновление модели** при накоплении новых завершённых торгов

### 9.2 Ограничения

- Все корреляции слабые (|r| < 0.15)
- Отрицательный R² — модель плохо работает на экстремальных значениях
- 64 активных лота без задатка (пока не завершились)
- Модель недооценивает экстремальные превышения
