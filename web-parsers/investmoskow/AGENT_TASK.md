   - Удалено 341 completed без итоговой цены (протоколы не распарсены)
   - Удалено `функциональное_назначение` (86.3% пропусков)
   - **Итого:** 2 820 лотов (2 498 train + 322 predict)

4. **Исправление Unknown округов**:
   - Было Unknown: 710 (25.2%)
   - Исправлено по координатам: 703 (99.0%)
   - Метод: поиск ближайшего центра округа по lat/lon

5. **Удаление Unknown и ТАО**:
   - Удалено 14 записей (7 Unknown + 7 ТАО)
   - Осталось: **2 806 записей** (2 236 train + 248 holdout + 64 active)
   - Модель переобучена на очищенных данных

## 4. МОДЕЛЬ

### 4.1 Архитектура

**Ансамбль: CatBoostRegressor + KNN (Look-Alike)**

| Компонент | Вес | Описание |
|-----------|-----|----------|
| **CatBoostRegressor** | 50% | Обобщённая модель на всех train данных |
| **KNN (Look-Alike)** | 50% | Среднее 5 ближайших соседей (округлено до шага аукциона) |

**Формула:**
```python
# KNN: среднее 5 ближайших соседей, округлённое до шага аукциона лота
pred_knn = round(mean(neighbor_targets) / step) * step

# Ансамбль
pred_ensemble = 0.5 * pred_catboost + 0.5 * pred_knn

# Финальное округление до шага аукциона
pred_rounded = round(pred_ensemble / step) * step
```

### 4.2 CatBoostRegressor

```python
CatBoostRegressor(
    iterations=500, learning_rate=0.01, depth=4, 
    l2_leaf_reg=10, min_data_in_leaf=20, 
    loss_function='MAE', random_seed=42
)
```

### 4.3 Результаты валидации (Holdout n=248)

| Метод | MAE | RMSE | R² | Корреляция |
|-------|-----|------|----|------------|
| **CatBoost только** | 26.72% | 37.8% | -0.245 | 0.264 |
| **KNN только** | 31.35% | 44.9% | -0.667 | 0.181 |
| **Ансамбль (50/50)** | **27.48%** | **39.4%** | **-0.174** | **0.127** |

### 4.4 Распределение ошибок ансамбля

| Метрика | Значение |
|---------|----------|
| Средняя ошибка | -1.4% |
| Медианная ошибка | 0.0% |
| Макс |ошибка| | 131.6% |
| Ошибка < 10% | 62.5% |
| Ошибка < 25% | 72.6% |

### 4.5 Ключевые выводы

**Что работает:**
- KNN часто точнее CatBoost для конкретных лотов
- Медианная ошибка = 0% — модель не систематически недооценивает
- Для лотов с нулевым превышением (32.7%) точность близка к 100%
- 62.5% предсказаний с ошибкой < 10%

**Проблемы:**
- Модель недооценивает экстремальные превышения (предсказывает 14%, реальность 199.5%)
- Все корреляции слабые (|r| < 0.15)
- Отрицательный R² — модель хуже медианного предсказания

## 7. ЗАПУСК

### 7.1 Streamlit приложение

```bash
python -m streamlit run model/app_validation.py --server.headless true --server.port 8501
```

**Функционал:**
- Карта 248 завершённых лотов с цветовой кодировкой ошибки
- При клике на лот:
  - Показывает 5 Look-Alike соседей (синие маркеры)
  - Красные пунктирные линии связи
  - Предсказания: CatBoost, KNN, Ансамбль
  - Ссылки на investmoscow.ru для каждого лота
- Детали соседей с реальной ценой превышения и датой завершения торгов
