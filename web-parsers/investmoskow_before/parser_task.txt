# Техническое задание — Парсер завершенных торгов investmoscow.ru

## 1. Описание задачи

Парсер для сбора данных о **завершённых торгах нежилых помещений** с сайта Инвестиционный портал Москвы: https://investmoscow.ru/tenders/

### Фильтры:
| Параметр | Значение |
|----------|----------|
| Тип объекта | Нежилое помещение |
| Действие | Купить (продажа) |
| Статус | Торги завершены |
| Год | 2025, 2026 |

## 4. Технические детали

### API
- **URL:** `POST https://api.investmoscow.ru/investmoscow/tender/v2/filtered-tenders/searchtenderobjects`
- **Пагинация:** pageNumber, pageSize=100
- **Фильтры:** objectKinds, objectTypes — статус не фильтруется на сервере
- **Ключевые поля:** id, startPrice, objectArea, pricePerSquare, requestEndDate, platformLink, subwayStations, additionalParams, floors, entranceTypeCodes

### Парсинг страниц
- Данные в SSR HTML (не нужен Playwright)
- Regex: `r'\{"label":\d+,"value":\d+\},"([^"]*)","([^"]*)"'`
- Извлекаются: задаток, шаг, итоговая цена, кадастр, даты, форма торгов

### Кэширование
- `data/page_cache.json` — кэш распарсенных страниц
- `data/parser_progress.json` — прогресс (обработанные ID)
