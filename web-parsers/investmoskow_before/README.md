# Парсер investmoscow.ru

Парсер для сбора данных о торгах по нежилым помещениям на [Инвестиционном портале Москвы](https://investmoscow.ru/tenders/).

## Что реализовано

### 1. Парсер завершенных торгов 2025–2026

```bash
python parser_completed.py
```

**Результат:** `data/investmoscow_completed_2026-04-04.csv` — **2 839 записей**

Поля: url, номер_лота, площадь, начальная/итоговая цена, задаток, шаг аукциона, превышение, адрес, кадастр, метро, этаж, этажность, форма торгов, даты, ссылка на roseltorg.

### 2. Геокодирование адресов

```bash
py geocode_addresses.py
```

**Результат:** `data/investmoscow_completed_2026-04-04_geocoded.csv` — **2 839 записей, 2 744 с координатами (96.7%)**

Добавлены поля: `latitude`, `longitude`. Используется Nominatim (OpenStreetMap) с кэшированием и валидацией по границам Москвы.

### 3. Парсинг протоколов (PDF + DOCX)

```bash
py parse_all_protocols.py
```

**Результат:** `data/protocols/protocol_cache.json` — **2 839 лотов**

| Метрика | Значение |
|---------|----------|
| Успешно распарсено | 2 171 (76.5%) |
| С участниками | 1 722 |
| Без участников (0) | 449 |
| Ошибки (нет протокола) | 668 |
| Форматы | 978 PDF + 1 154 DOCX |

Извлекается: количество участников, победитель, цена победителя, второе место.

### 4. Аналитика

```bash
python run_analytics.py
```

Или открыть `analytics_completed.ipynb` в Jupyter.

**Результат:** 6 графиков в `data/charts/` + отчёт `data/analytics_summary.md`

### 5. Streamlit дашборд

```bash
streamlit run app_map.py
```

Деплой: https://realrobothistory.streamlit.app/

**Функции:**
- Интерактивная карта Москвы с точками лотов
- Фильтры: округ, год, статус, площадь, цена, этаж, превышение
- Scatter plot: превышение цены vs количество участников
- Таблица статистики по диапазонам участников
- Таблица данных с ссылкой на investmoscow.ru

## Цветовая схема на карте

| Цвет | Значение |
|------|----------|
| ⚫ Серый | Не состоялись (0 участников или снижение цены) |
| 🟢 Зелёный | 0% (стартовая цена) |
| 🟡 Жёлтый | ~50% (среднее превышение) |
| 🔴 Красный | 100%+ (высокое превышение) |
