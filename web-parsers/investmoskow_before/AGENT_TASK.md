## Что осталось сделать

### ⬜ Этап 2: Парсинг протоколов (roseltorg.ru / torgi.gov.ru)

**Цель:** получить данные, которых нет на investmoscow.ru:
- Количество участников торгов
- Название компании-победителя
- Ссылки на протоколы (рассмотрения заявок, подведения итогов)

**Подход:**
1. Из CSV берём `platformLink` — прямая ссылка на roseltorg для каждого лота
2. Переходим по ссылке, парсим страницу процедуры на roseltorg.ru
3. Извлекаем: количество поданных заявок, победитель, протоколы
4. Обновляем CSV новыми полями

**Сложность:** 🟡 Средняя — roseltorg может требовать JS-рендеринг

### ⬜ Этап 3: Парсинг активных торгов

**Цель:** парсинг торгов со статусом «Приём заявок» (актуальные лоты)

**Подход:** аналогичен parser.py, но с расширенными полями из parser_completed.py

**Фильтры API:**
```python
"tenderStatus": "nsi:tender_status_tender_filter:1"  # Приём заявок
```

## Технические находки (для следующего агента)

### API investmoscow.ru
- **Endpoint:** `POST https://api.investmoscow.ru/investmoscow/tender/v2/filtered-tenders/searchtenderobjects`
- API **не фильтрует** на сервере — нужно скачивать всё и фильтровать на клиенте по `requestEndDate`
- **Статус не возвращается** в API — определяется по дате: если `requestEndDate` прошла → «Завершено»
- **Итоговая цена, задаток, шаг аукциона** — только на странице лота (SSR HTML), не в API
- **platformLink** — прямая ссылка на roseltorg в данных API

### Парсинг страниц лотов
- Данные встроены в SSR HTML в JSON-формате
- Паттерн: `{"label":N,"value":N},"Метка","Значение"`
- Regex: `r'\{"label":\d+,"value":\d+\},"([^"]*)","([^"]*)"'`
- Доступные поля: кадастровый номер, задаток, шаг аукциона, итоговая цена, даты торгов, форма проведения

### Окружение
- Python 3.9.13 (conda)
- `pip install requests beautifulsoup4 pandas matplotlib seaborn`
- Playwright НЕ нужен для парсинга страниц лотов — данные в SSR HTML
