**Структура приложения:**
```

├── data/
```

**Ключевые функции:**
- 🗺️ **Интерактивная карта** (Folium) с цветовой схемой:
  - ⚫ Серый = 0 участников или снижение цены
  - 🟢 Зелёный = 0% превышения
  - 🟡 Жёлтый = ~50% превышения
  - 🔴 Красный = 100%+ превышения
- 🔍 **Фильтры:** округ, год, статус, площадь, цена, этаж, превышение
- 📊 **Scatter plot:** превышение vs количество участников
- 📋 **Таблица статистики** по диапазонам участников
- 📋 **Таблица данных** со ссылками на investmoscow.ru и roseltorg.ru

**Важно для деплоя:**
- `protocol_cache.json` включён в git (1.3 МБ) — данные доступны сразу
- `@st.cache_data(ttl=3600)` — кэш обновляется каждый час
- BASE_DIR определяется автоматически (работает и локально, и на Streamlit Cloud)
- При изменениях нужен **Redeploy** через Settings → Restart app

## Технические находки

### API investmoscow.ru
- **Endpoint:** `POST https://api.investmoscow.ru/investmoscow/tender/v2/filtered-tenders/searchtenderobjects`
- API **не фильтрует** на сервере — нужно скачивать всё и фильтровать по `requestEndDate`
- **Итоговая цена, задаток, шаг аукциона** — только на странице лота (SSR HTML)
- **Протоколы** — скачиваются через API: `https://api.investmoscow.ru/investmoscow/tender/v1/tender/getattachedfilebyid?attachmentId=XXXXX`

### Парсинг протоколов
- **DOCX:** Таблица участников — искать заголовок "№ п/п" или "Место", считать строки минус 1
- **PDF:** Таблица участников — искать "номер заявки" или "порядковый", извлекать через pdfplumber.extract_tables()
- **Важно:** Считать допущенные заявки, а не реально участвовавших (таблица предложений может быть пустой)

### Окружение
- Python 3.9.13 (conda)
- `pip install requests beautifulsoup4 pandas matplotlib seaborn pdfplumber python-docx streamlit folium streamlit-folium`
- Playwright **НЕ нужен** — данные в SSR HTML
