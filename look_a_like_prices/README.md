# look_a_like_prices — оценка стоимости коммерческой недвижимости

Streamlit-приложение для подбора аналогов и предсказания цены/ставки аренды для лотов на торгах investmoscow.

## Что делает

Три вкладки для выбранного лота (одного или нескольких):

**Продажа — аналоги**
- Аналогичные объявления о продаже на карте (ЦИАН + Яндекс.Недвижимость)
- Оценка цены/м² двумя методами и их взвешенная комбинация (ползунок α)
- Количество квартир и жителей в пешей доступности (реестр ЖКХ)

**Аренда + окупаемость**
- Аналоги аренды на карте (зелёные маркеры)
- Территориальная ставка аренды руб/м²/мес
- Калькулятор окупаемости: цена покупки + ползунок ремонта (0–500 тр/м²) → срок окупаемости в годах

**Точность метода**
- MAPE XGBoost по GroupKFold и MAPE территориальной медианы по LOO-CV

## Методология

### Данные

| Источник | Объём | Назначение |
|---|---|---|
| ЦИАН + Яндекс.Недвижимость | 9 410 объявлений продажи (после дедупа) | Аналоги продажи |
| ЦИАН + Яндекс.Недвижимость | 18 514 объявлений аренды (после дедупа) | Аналоги аренды |
| ГИС ЖКХ | 36 019 жилых домов Москвы | Аудитория (квартиры/жители) |
| Тип входа | 1 362 объявления, спарсены с Яндекс | Признак модели |

**Дедупликация**: объявления группируются по (координаты ~50м + этаж + площадь-бакет), оставляется самое свежее. Исходный sale.csv содержал 44% повторов (ре-листинги + один объект на ЦИАН и Яндексе одновременно).

### Модель 1 — территориальная медиана

Медиана цены/м² аналогов в радиусе R с тем же этажом и похожей площадью (±50%).
Если тип входа известен и аналогов с таким же входом ≥ 2 — фильтруем дополнительно.

- Оценка точности: **LOO-CV** — каждый объект предсказывается своими соседями (исключая 100м вокруг), сам в предсказании не участвует
- MAPE ≈ 34%, покрытие ≈ 52%

### Модель 2 — XGBoost (hedonic model)

Предсказание log(цена/м²) по признакам:

| Признак | Важность |
|---|---|
| Этаж (цоколь / 1 / 2 / 3+) | ~57% суммарно |
| Координаты lat/lng | ~18% |
| Расстояние до метро | ~8% |
| Площадь | ~6% |
| Квартир в 400м и 800м | ~8% |
| Тип входа | ~3% |

- MAPE = **31%**, покрытие 100%

### Кросс-валидация: GroupKFold по пространственным кластерам

Простой KFold даёт смещённую оценку: если одно здание есть и в train, и в test, модель «видела» почти идентичный объект — MAPE получается искусственно низкий (раньше выходило 20.6%).

**GroupKFold**: объекты одного здания + одного этажа всегда попадают в один фолд.

Группа = `round(lat × 2000) _ round(lng × 2000) _ этаж`

Сетка ~50м по координатам. Сравнивали три стратегии группировки:

| Стратегия | Групп | MAPE |
|---|---|---|
| Сетка 50м + этаж | 3 738 | **31.0%** |
| DBSCAN eps=50м + этаж | 3 501 | 31.6% |
| MeanShift bandwidth=50м + этаж | 3 441 | 31.7% |

Все три дают одинаковый результат — выбрана сетка как самая быстрая и воспроизводимая.

### Итоговая оценка

```
Цена/м² = α × территориальная медиана + (1−α) × XGBoost
```

Оптимальный α = 0.05, MAPE комбинации ≈ **27%**.  
α выставляется в интерфейсе (ползунок 0–1).

## Структура

```
app.py                        — Streamlit-приложение (3 вкладки)
_build_model.py               — обучение XGBoost + GroupKFold CV
_compare_clustering.py        — сравнение стратегий группировки для GroupKFold
_dedup_sale.py                — дедупликация sale.csv → sale_dedup.csv
_build_buildings.py           — сборка buildings_moscow.parquet из ЖКХ данных
_scrape_entrance.py           — парсинг типа входа ЦИАН (с логикой ретрая при 403)
_scrape_yandex.py             — парсинг типа входа Яндекс (продажа)
_scrape_yandex_arenda.py      — парсинг типа входа Яндекс (аренда)
_normalize_entrance.py        — нормализация raw-значений типа входа
_analyze_entrance.py          — анализ влияния типа входа на цену
_loo_radii.py                 — подбор оптимального радиуса
_loo_features.py              — отбор признаков
data/
  sale_dedup.csv              — 9 410 объявлений продажи после дедупа
  arenda_dedup.csv            — 18 514 объявлений аренды после дедупа
  buildings_moscow.parquet    — 36k жилых домов: координаты, квартиры
  hedonic_xgb.json            — обученная XGBoost модель
  hedonic_features.json       — список признаков модели
  sale.csv/                   — исходный sale.csv (не в git, 16k строк)
  arenda.csv/                 — исходный arenda.csv (не в git, 116 МБ)
```
