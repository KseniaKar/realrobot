# look_a_like_prices — оценка стоимости коммерческой недвижимости

Streamlit-приложение для подбора аналогов и предсказания цены/ставки аренды для лотов на торгах investmoscow.

## Что делает

Три вкладки для выбранного лота (одного или нескольких):

**Продажа — аналоги**
- Аналогичные объявления о продаже на карте (ЦИАН + Яндекс.Недвижимость)
- Фильтр по типу объекта (офис / торговое / ПСН / …)
- Тип входа в попапе и таблице аналогов
- Оценка цены/м² двумя методами и их взвешенная комбинация (ползунок α)
- Upside (рынок − аукцион) с пессимистичным сценарием −27% (MAPE Combined α=0.05)
- Количество квартир и жителей в пешей доступности (реестр ЖКХ)

**Аренда + окупаемость**
- Аналоги аренды на карте (зелёные маркеры)
- Ставка аренды двумя методами: территориальная медиана и **XGBoost-модель** (MAPE 31%)
- Калькулятор окупаемости: цена покупки + ползунок ремонта (0–500 тр/м²) → срок окупаемости
- Пессимистичный сценарий (−31% к ставке)
- Cap rate на аукционной и рыночной цене; окупаемость при рыночной цене

**Точность метода**
- MAPE XGBoost (продажа и аренда) по GroupKFold и MAPE территориальной медианы по LOO-CV

## Методология

### Данные

| Источник | Объём | Назначение |
|---|---|---|
| ЦИАН + Яндекс.Недвижимость | 9 410 объявлений продажи (после дедупа) | Аналоги и признаки продажи |
| ЦИАН + Яндекс.Недвижимость | 16 565 объявлений аренды (после дедупа) | Аналоги и признаки аренды |
| ГИС ЖКХ | 36 019 жилых домов Москвы | Аудитория (квартиры/жители) |
| Тип входа (продажа) | 1 392 объявления, Яндекс | Признак модели продажи |
| Тип входа (аренда) | 2 905 объявлений, Яндекс | Признак модели аренды |

**Дедупликация**: объявления группируются по (координаты ~50м + этаж + площадь-бакет), оставляется самое свежее. Исходный sale.csv содержал 44% повторов (ре-листинги + один объект на ЦИАН и Яндексе одновременно).

**Фильтрация выбросов** (продажа): площадь ≥ 15 м², цена/м² 50k–3M руб. Фильтр снизил MAPE территориальной медианы с 53% до 35%.  
**Фильтрация выбросов** (аренда): площадь ≥ 15 м², цена/м²/мес 200–100 000 руб.

---

### Модель продажи

#### Территориальная медиана (baseline)
Медиана цены/м² аналогов в радиусе R с тем же этажом и похожей площадью (±50%).
Если тип входа известен и аналогов с таким же входом ≥ 2 — фильтруем дополнительно.

- Оценка: **LOO-CV** (исключаем 100м вокруг целевого объекта)
- MAPE ≈ **35%**, покрытие ≈ 54%

#### XGBoost (hedonic model)

Предсказание log(цена/м²) по признакам:

| Признак | Важность |
|---|---|
| Этаж (цоколь / 1 / 2 / 3+) | ~39% |
| Медиана аренды в 700м/1500м (кросс-сигнал) | ~22% |
| Координаты lat/lng | ~10% |
| Вид объекта (офис/торговое/ПСН) | ~9% |
| Расстояние до метро | ~6% |
| Кол-во продаж/аренд в 700м | ~8% |
| Расстояние до Кремля | ~5% |
| Площадь, квартиры в 400/800м | ~8% |
| Тип входа (бинарный) | ~3% |

- MAPE = **31%**, покрытие 100%

#### Итоговая оценка продажи

```
Цена/м² = α × территориальная медиана + (1−α) × XGBoost
```

α = 0 (чистый XGBoost) оптимален. α выставляется в интерфейсе (ползунок 0–1).

- MAPE Combined (α=0.05) = **27%** — лучшая оценка для пессимистичного сценария

---

### Модель аренды

#### Территориальная медиана (baseline)
Медиана аренды/м²/мес аналогов в радиусе R с тем же этажом и похожей площадью.

- MAPE ≈ **44.6%**, покрытие ≈ 68%

#### XGBoost (hedonic rent model)

Предсказание log(аренда/м²/мес) по признакам:

| Признак | Важность |
|---|---|
| Этаж цоколь | ~12.5% |
| Медиана продажи в 700м/1500м (кросс-сигнал) | ~21.8% |
| Вид объекта (офис/торговое/ПСН) | ~18.2% |
| Этаж 1 | ~9.1% |
| Расстояние до метро | ~5.1% |
| Расстояние до Кремля | ~4.7% |
| Кол-во аренд/продаж в 700м | ~8.2% |
| Координаты lat/lng | ~6.3% |
| Площадь, квартиры в 400/800м | ~7.9% |
| Тип входа (бинарный) | ~3.3% |

- MAPE = **31%**, покрытие 100%

Кросс-сигнал `median_sale_700m` / `_1500m` из данных продажи снижает MAPE и устраняет проблему нулевого покрытия территориальной медианы (32% объектов без соседей в 700м).

---

### Кросс-валидация: GroupKFold по пространственным кластерам

Простой KFold даёт смещённую оценку (раньше выходило 20.6% вместо реальных 29–31%).

**GroupKFold**: объекты одного здания + одного этажа всегда попадают в один фолд.

Группа = `round(lat × 2000) _ round(lng × 2000) _ этаж`  (сетка ~50м)

## Структура

```
app.py                          — Streamlit-приложение (3 вкладки)
_build_model.py                 — обучение XGBoost продажи + GroupKFold CV
_build_rent_model.py            — обучение XGBoost аренды + GroupKFold CV
_compare_clustering.py          — сравнение стратегий группировки для GroupKFold
_dedup_sale.py                  — дедупликация sale.csv → sale_dedup.csv
_build_buildings.py             — сборка buildings_moscow.parquet из ЖКХ данных
_scrape_entrance.py             — парсинг типа входа ЦИАН (с логикой ретрая при 403)
_scrape_yandex.py               — парсинг типа входа Яндекс (продажа)
_scrape_yandex_arenda.py        — парсинг типа входа Яндекс (аренда)
_normalize_entrance.py          — нормализация raw-значений типа входа
_analyze_entrance.py            — анализ влияния типа входа на цену
_loo_radii.py                   — подбор оптимального радиуса
_loo_features.py                — отбор признаков
data/
  sale_dedup.csv                — 9 410 объявлений продажи после дедупа
  arenda_dedup.csv              — 16 565 объявлений аренды после дедупа
  buildings_moscow.parquet      — 36k жилых домов: координаты, квартиры
  hedonic_xgb.json              — XGBoost модель продажи
  hedonic_features.json         — признаки модели продажи
  rent_xgb.json                 — XGBoost модель аренды
  rent_features.json            — признаки модели аренды
  sale.csv/                     — исходный sale.csv (не в git)
  arenda.csv/                   — исходный arenda.csv (не в git)
_entrance_results.csv           — тип входа продажа (1 392 объявления)
_entrance_results_arenda.csv    — тип входа аренда (2 905 объявлений)
```
