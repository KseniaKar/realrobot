# look_a_like_prices — оценка стоимости коммерческой недвижимости

Streamlit-приложение для подбора аналогов продажи и предсказания цены для лотов на торгах investmoscow.

## Что делает

Для выбранного лота на торгах показывает:
- аналогичные объявления о продаже на карте (ЦИАН + Яндекс.Недвижимость)
- оценку цены/м² двумя методами и их взвешенную комбинацию
- количество квартир и жителей в пешей доступности (из реестра ЖКХ)

## Методология оценки

### Данные
- **1 164 объявления** о продаже коммерческой недвижимости в Москве (снимок февраль 2026, ЦИАН + Яндекс)
- **36 019 жилых домов** Москвы с координатами и числом квартир (ГИС ЖКХ, май 2026)
- Тип входа спарсен с ЦИАН для 886 объявлений (Playwright)

### Модель 1 — территориальная медиана
Медиана цены/м² аналогов в радиусе R метров с тем же этажом и похожей площадью (±50%).
- MAPE = 24%, покрытие 25% (для 75% лотов аналогов в радиусе недостаточно)

### Модель 2 — XGBoost (hedonic model)
Предсказание цены/м² по 14 признакам:

| Признак | Важность |
|---|---|
| Этаж (1 / 2 / 3+ / цоколь) | 40% суммарно |
| Тип входа (отдельный / общий / со двора) | 22% суммарно |
| Координаты (lat / lng) | 13% |
| Расстояние до метро | 8% |
| Площадь | 6% |
| Квартир в 400м и 800м | 6% |

- MAPE = 28%, покрытие **100%**
- Обучение: LOO-CV на 1131 объявлении, log(цена/м²) как целевая переменная

### Итоговая оценка
```
Цена = α × территориальная + (1−α) × XGBoost
```
Оптимальный α по LOO-CV = 0.10, MAPE комбинации = **16%**.

α выставляется риэлтором в интерфейсе (ползунок 0–1) в зависимости от наличия близких аналогов и доверия к модели.

## Структура

```
app.py                        — Streamlit-приложение
_build_buildings.py           — сборка buildings_moscow.parquet из ЖКХ данных
_build_model.py               — обучение XGBoost, LOO-CV, сохранение модели
_parse_entrance_cian_full.py  — парсинг типа входа с ЦИАН (Playwright)
_normalize_entrance.py        — нормализация raw-значений типа входа
_analyze_entrance.py          — анализ влияния типа входа на цену
_loo_radii.py                 — подбор оптимального радиуса
_loo_features.py              — отбор признаков
data/
  buildings_moscow.parquet    — 36k жилых домов: FIAS, координаты, квартиры
  moscow_addresses.csv        — FIAS → координаты (от Дмитрия Колодезева)
  hedonic_xgb.json            — обученная XGBoost модель
  hedonic_features.json       — список признаков модели
  zhk/                        — исходные CSV ГИС ЖКХ (2.7 GB, не в git)
excel2-30025-1.xlsx           — выгрузка объявлений о продаже
```
