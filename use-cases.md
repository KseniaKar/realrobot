# Use Cases: Обращение в агентства по коммерческой недвижимости

## 1. Покупка коммерческой недвижимости

### 1.1. Инвестиционные цели
- Приобретение объектов для последующей сдачи в аренду
- Вложение капитала в ликвидные активы
- Диверсификация инвестиционного портфеля

### 1.2. Для собственного бизнеса
- Поиск помещения под офис компании
- Покупка торговых площадей для ритейла
- Приобретение складских помещений
- Покупка помещений под производство

---

## 2. Аренда коммерческой недвижимости

### 2.1. Офисные помещения
- Поиск офиса класса A, B, C
- Коворкинг и гибкие пространства
- Отдельно стоящие здания под штаб-квартиру

### 2.2. Торговые площади
- Аренда магазина в ТЦ
- Стрит-ритейл (первый этаж)
- Торговые павильоны
- Шоу-румы

### 2.3. Складская недвижимость
- Складские комплексы класса A, B
- Холодильные склады
- Логистические центры

### 2.4. Общественное питание
- Помещения под рестораны и кафе
- Фуд-корты в ТЦ
- Отдельно стоящие здания

---

## 3. Продажа коммерческой недвижимости

### 3.1. Выход из актива
- Продажа инвестиционного объекта
- Реализация непрофильных активов

### 3.2. Смена локации бизнеса
- Продажа текущего помещения в связи с переездом

---

## 4. Консультационные услуги

### 4.1. Оценка рыночной стоимости
- Предпродажная оценка объекта
- Оценка для инвестиционных целей

### 4.2. Анализ рынка
- Исследование локальных рынков недвижимости
- Бенчмаркинг арендных ставок
- Анализ конкурентного окружения

### 4.3. Юридическое сопровождение
- Проверка юридической чистоты объекта
- Сопровождение сделок
- Консультации по налогообложению

---

## 5. Управление недвижимостью (Property Management)

### 5.1. Эксплуатация объектов
- Техническое обслуживание зданий
- Управление арендными потоками
- Взаимодействие с арендаторами

### 5.2. Оптимизация доходов
- Повышение арендной привлекательности
- Ревитализация объектов
- Редевелопмент территорий

---

## 6. Инвестиционно-девелоперские проекты

### 6.1. Строительство с нуля
- Подбор земельных участков
- Консультации по концепции проекта
- Поиск инвесторов/партнёров

### 6.2. Реконструкция и редевелопмент
- Адаптация исторических зданий
- Смена функционального назначения
- Модернизация существующих объектов

---

## 7. Специфические задачи

### 7.1. Сеть объектов
- Подбор помещений для сетевых бизнесов (ритейл, HoReCa)
- Единые стандарты по сети
- Масштабирование в новые регионы

### 7.2. Корпоративные клиенты
- Консолидация офисов компании
- Релокация бизнеса
- Оптимизация портфеля недвижимости

### 7.3. Франшизы
- Подбор локаций под франчайзинговые проекты
- Согласование с франчайзером

---

## 8. Причины обращения к агентству

| Причина | Описание |
|---------|----------|
| **Экспертиза рынка** | Доступ к актуальной рыночной информации и аналитике |
| **База объектов** | Доступ к закрытым/эксклюзивным предложениям |
| **Экономия времени** | Агент берёт на себя поиск, показы, переговоры |
| **Переговоры** | Профессиональное ведение переговоров по цене и условиям |
| **Юридическая защита** | Проверка документов, сопровождение сделки |
| **Оценка справедливой цены** | Избежание переплаты или занижения при продаже |
| **Комплексный сервис** | От поиска до управления объектом |

---

## 9. Типичные боли клиентов

- Недостаток прозрачной информации о рынке
- Сложности с оценкой реальной стоимости объекта
- Риск юридических проблем при сделке
- Отсутствие времени на самостоятельный поиск
- Сложности в переговорах с контрагентами
- Незнание локальных особенностей и трендов
