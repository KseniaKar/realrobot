# Агент для поиска недооцененной коммерческой недвижимости.
Агент находит недооцененную коммерческую недвижимость.
Проект помогает инвесторам быстро оценивать варианты, не тратя время на ручной поиск и оценку.

## Краткое введение
Мы находим недооцененные объекты коммерческой недвижимости и понимаем, сколько на них можно получить прибыли.
Сначала агент ищет варианты по цене ниже рынка, затем рассчитывает их доходность от аренды или перепродажи.
В итоге мы предлагаем эти объекты тем, кому они пригодятся: малого бизнесу для своих точек, либо крупным компаниям и инвесторам для вложений.

## Контекст и проблематика
Найти недооцененный объект вручную сложно — выгодные варианты быстро теряются в общем потоке объявлений.
Главная проблема в том, что на оценку доходности каждого помещения уходит слишком много времени,
а без быстрых расчетов невозможно понять, стоит ли объект внимания. В итоге малый бизнес переплачивает за аренду,
а инвесторы упускают прибыль, потому что не могут оперативно мониторить весь рынок и находить в нем скрытую выгоду.

## Данные

### Источники
| Источник | Что собираем | Частота |
|----------|--------------|---------|
| Сайт торгов | Активные лоты, история завершённых торгов | Ежедневно |
| Авито, ЦИАН, др. агрегаторы | Объявления аренды коммерческой недвижимости | Ежедневно |
| Авито, ЦИАН, др. агрегаторы | Объявления продажи коммерческой недвижимости | Ежедневно |

### Структура данных
- **Лоты с торгов:** адрес, площадь, этаж, цена, описание, фото, ссылка на торги
- **Аренда:** локация, площадь, цена/мес, этаж, тип помещения, контакты
- **Продажа:** локация, площадь, цена, этаж, тип помещения, контакты
- **История торгов:** количество участников, итоговая цена, превышение над стартовой

### Объём
- ~50–100 новых лотов с торгов в день
- ~1 000–3 000 активных объявлений аренды/продажи в базе
- История завершённых торгов: накапливается

### Качество
- Данные парсятся автоматически, требуют валидации
- Look-alike подбор: 5–10 аналогов на каждый лот
- Пользовательская разметка через галочки (подтверждение/отклонение аналогов)

## Методология

### 1. Генерация описаний и вариантов использования
- Для каждого лота нейросеть генерирует:
  - Текстовое описание объекта
  - Варианты использования (парикмахерская, склад, офис, кафе и т.д.)
  - Теги для фильтрации

### 2. Look-alike подбор аналогов
- **Аренда:** поиск 5–10 похожих объявлений по локации, площади, формату
- **Продажа:** поиск 5–10 похожих объектов для оценки рыночной цены
- Расчёт средней арендной ставки и цены продажи

### 3. Расчёт окупаемости
- Окупаемость = Цена лота / (Арендная ставка × 12)
- Показатель «цена при 6-летней окупаемости» — целевой ориентир для торгов
- Сравнение по форматам: «как парикмахерская — 8 лет, как склад — 14 лет»

### 4. Интерактивная калибровка
Пользователь отмечает галочками:
- Подходящие форматы использования → перегенерация описания
- Подходящие аналоги аренды → пересчёт ставки и окупаемости
- Подходящие аналоги продажи → пересчёт рыночной цены

### 5. Индикаторы ликвидности и конкурентности
- **Ликвидность аренды/продажи:** предупреждение, если аналогов мало или нет
- **Конкурентность торгов:** среднее число участников и типичное превышение цены на основе истории

## Результаты

### Продукт
- **AI-агент поиска недооценённой коммерческой недвижимости** — см. [products.md](products.md)
- **Трекер изменений рынка** — мониторинг рыночных сигналов
- **Подбор прибыльной модели эксплуатации** — ранжирование сценариев использования

### Экономика
| Показатель | Значение |
|------------|----------|
| Стоимость лота (средняя) | ~30 млн руб |
| Время анализа лота вручную | ~4 часа |
| Время анализа с продуктом | 15–30 минут |
| Эффект для инвестора | 1–3 млн руб/год (доп. доходность) |
| Цена подписки | 5 000 руб за 50 лотов |

### Ценность
- **Экономия времени:** 3.5 часа × 1 000 руб/час = 3 500 руб на 1 лот
- **Предотвращённые убытки:** разница между окупаемостью 6 и 15 лет = ~3 млн руб/год
- **Разблокирование сделок:** инвестор, который не участвовал без продукта, делает первую сделку

Подробная оценка эффекта: [spec/value-estimation.md](spec/value-estimation.md)
